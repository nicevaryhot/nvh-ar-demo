# NVH AR Demo

Public static demo built from the private nicevaryhot/nvh-ar-studio source (e5af82a).

- Commerce fitting: https://nicevaryhot.github.io/nvh-ar-demo/
- Standalone camera: https://nicevaryhot.github.io/nvh-ar-demo/camera/
- Original 3D prototypes: https://nicevaryhot.github.io/nvh-ar-demo/?type=models

Product selection, local photo preview and camera controls are available. AI synthesis, recommendations and account history require the separate AWS/Cloudflare API; it is not connected to this published build yet. No simulated AI output is presented as a generated result.

TH product images/prices are a Lovable catalog snapshot, not live inventory. Other accessory overlays and 3D models are illustrative and unverified. No production backend, credentials, customer photos or shopping API are included.
